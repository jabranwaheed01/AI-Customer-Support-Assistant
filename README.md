# AI Customer Support Assistant

A simple AI-powered Customer Support Assistant built with **Python, LangChain, and LLaMA 3.2**.

### Features

* Customer query classification
* Categories: **Billing, Technical Issue, General Inquiry**
* Conversation memory using JSON
* Remembers user's name
* Exit command handling
* LLM-powered responses using Ollama

### Tech Stack

* Python
* LangChain
* Ollama
* LLaMA 3.2
* JSON

### How It Works

The assistant receives a customer query, uses the previous conversation history for context, analyzes the problem, and classifies it into the most appropriate support category.

### Run

```bash
python main.py
```
